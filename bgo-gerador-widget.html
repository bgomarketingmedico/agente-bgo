Como criar um novo cliente

Passo a passo completo — do zero ao widget no ar

🏥
1. CRIAR O CLIENTE
Cadastro e configuração no painel
1

Criar novo cliente no painel

Clique em "+ Novo Cliente" no menu superior. Preencha o nome da clínica e o número do WhatsApp no formato 5561999990000 (DDI + DDD + número, só dígitos).

2

Configurar aparência e campos

Defina o título, subtítulo e cor do botão. Ative Especialidade ou Convênio se necessário. Adicione campos personalizados se a clínica precisar de informações extras.

⚙️
2. CONFIGURAR O GOOGLE APPS SCRIPT
Uma vez por cliente — cria a planilha de leads no Drive
3

Abrir o Google Apps Script

Acesse script.google.com → clique em Novo projeto → nomeie como Widget B.GO — Nome do Cliente.

4

Colar o código e executar

No painel, clique em Gerar widget → aba ⚙️ Apps Script → copie todo o código → cole no editor do Apps Script, apagando o código padrão → salve com Ctrl+S.

Selecione a função configurarCliente no menu → clique em ▶ Executar. Na primeira vez o Google pedirá permissão — clique em Revisar permissões → Avançado → Permitir.

5

Publicar como Web App e copiar a URL

Clique em Implantar → Nova implantação → Tipo: App da Web → Executar como: Eu → Quem acessa: Qualquer pessoa → Implantar → copie a URL gerada.

6

Colar a URL no painel e gerar novamente

Volte ao painel → campo URL do Google Apps Script → cole a URL → clique em Gerar widget novamente para o snippet incluir o webhook.

🚀
3. COLOCAR NO AR
Site, página WhatsApp e rastreamento de origem
7

Copiar o snippet e colar no site

Aba 💻 Snippet do Site → copie o código → cole no site do cliente antes do </body>.

Wix: Configurações → Código personalizado → + Adicionar → cole → Todas as páginas → Corpo - fim → Aplicar → Publicar.
WordPress: Plugin WPCode → + Snippets → HTML → cole → ativar → Salvar.

8

Subir a página WA no GitHub

Clique em ⬇️ Baixar página do cliente → salva o arquivo nome-cliente.html.

🥇 1º cliente (pasta wa/ ainda não existe): GitHub → agente-bgo → Add file → Create new file → no campo do nome digite wa/nome-cliente.html (a barra / cria a pasta) → abra o arquivo no Bloco de Notas → cole o conteúdo → Commit changes.

🔁 Próximos clientes: GitHub → pasta wa/ → Add file → Upload files → arraste o arquivo → Commit changes.

Aguarde ~30s e a URL estará no ar.

9

Usar a URL nos botões do site

A URL limpa bgomarketingmedico.github.io/agente-bgo/wa/nome-cliente pode ser usada em qualquer botão do site.

Wix: clique no botão → Conectar ao link → Web address → cole a URL → deixe "Abrir na mesma janela" → Salvar → Publicar.
WordPress: clique no botão → campo link → cole a URL → não marque "abrir em nova aba" → Atualizar.
O formulário abre sobre a mesma página; o visitante pode fechar no "✕" e continuar navegando.

⚠️ Importante — rastreamento dos botões: para esses leads que chegam pela URL registrarem de onde vieram (Google orgânico, Instagram, anúncio) na planilha, o site precisa ter o script do passo 10 instalado. Sem ele, esses leads chegam como "direto".
10

Rastrear a origem do lead (essencial p/ os botões de URL)

Faz a planilha mostrar de onde o lead veio (busca google orgânico, instagram, tráfego pago…) em vez de "direto". Vale para o botão flutuante e principalmente para os botões que usam a URL (passo 9) — sem esse script, os leads da URL chegam sempre como "direto". Cole uma única vez no site do cliente, antes do </body>:

<script src="https://bgomarketingmedico.github.io/agente-bgo/bgo-origem.js"></script>

Wix: Configurações → Código personalizado → + Adicionar código → cole acima → marque Todas as páginas → posição Corpo - fim → Aplicar → Publicar.
WordPress: plugin WPCode → + Adicionar snippet → HTML → cole → ative → Salvar.
É a mesma linha para todos os clientes. Cola uma vez por site e nunca mais mexe.

✓

Testar tudo

Acesse o site do cliente e clique no botão verde do WhatsApp. Preencha o formulário com dados fictícios e confirme que a linha apareceu na planilha em B.GO — Leads de Clientes no Google Drive. ✅
